Sync wrappers (`call_with_retry`, `call_with_retry_and_fallback`, `call_with_tier_fallback`, `run_agent`) now drive the shared async loops without an event loop. The #382/#392 dedup refactor wrapped them in `asyncio.run(...)`, which invoked the caller's sync `fn` inside a running loop — crashing every run_sync-style callable (pydantic-ai `Agent.run_sync`, claude_sdk tool agent) with `RuntimeError: asyncio.run() cannot be called from a running event loop` / `This event loop is already running`.
