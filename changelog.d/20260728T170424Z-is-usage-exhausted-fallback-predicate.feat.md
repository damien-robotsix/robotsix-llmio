Add `is_usage_exhausted` predicate and thread `should_fallback` through `run_agent`/`arun_agent`. Callers can now pass `should_fallback=is_usage_exhausted` to degrade to the fallback model only when the primary's usage is exhausted (pydantic-ai `UsageLimitExceeded` or `ClaudeSDKUsageExhaustedError`), while still failing loudly on genuine errors — instead of the previous fall-back-on-everything default.
