`docs/modules.yaml` now conforms to the robotsix-modules schema: kebab-case module ids (the old `robotsix_llmio-*` ids with underscores were schema-invalid), the required description on every module (core and claude-sdk lacked one), directory globs instead of per-file test lists, a top-level `package` field, and new `dev-tooling` / `project-root` modules so every tracked file is claimed (mirroring robotsix-mill's taxonomy).
