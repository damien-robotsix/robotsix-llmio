Classify an expired or rejected Claude OAuth credential as its own terminal failure instead of a transient one. The CLI streams `Failed to authenticate. API Error: 401 ...` as assistant text and then exits non-zero, which `claude_agent_sdk` collapses into its generic `returned an error result: success` message — so a dead credential looked retryable, burned all three attempts against the same expired token, and surfaced as an opaque `ClaudeSDKAPIError` transport failure. `_stream_query` now raises the new `ClaudeSDKAuthError` from both shapes (collapsed exception and clean `is_error=True` result), and `is_claude_sdk_transient` excludes it so it fails fast. Callers can catch it alongside `ClaudeSDKUsageExhaustedError` to degrade to a different capability tier and keep serving while the credential is dead.
